# 🌾 Village Farming Directory

A full-stack web application for registering farmers and managing their personal and farming information.

## 📌 About the Project

Village Farming Directory helps maintain farmer records digitally. Users can register, log in, view farmer information, add new farmers, edit records, delete records, and search farmers.

## 🚀 Features

- Farmer Registration and Login
- Dashboard with farming statistics
- Add, View, Edit, and Delete farmer records (CRUD)
- Search farmers by name, village, or crop
- Session-based authentication
- MySQL database integration
- Responsive user interface

## 🛠️ Technologies Used

- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- MySQL
- HTML5 & CSS3
- Bootstrap 5
- Maven
- Eclipse IDE
